# Hermit releases

[Hermit](https://github.com/guseoh/hermit)의 Windows 설치 파일과 자동 업데이트 파일(`latest.yml`)을 배포하는 저장소입니다. 소스 코드는 이 저장소에 없습니다.

- 설치: [Releases](https://github.com/guseoh/hermit-releases/releases)에서 `Hermit-Setup-<버전>.exe`를 받아 실행합니다. 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜹니다("추가 정보 → 실행").
- 업데이트: 설치한 앱이 시작 10초 뒤와 6시간마다 이 저장소의 최신 릴리스를 확인해 받아 두고, 다시 시작할 때 설치합니다.
